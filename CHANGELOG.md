# Changelog

All notable changes to this add-on will be documented in this file.

## 1.0.0 beta

### Added
- Initial release of Crimson Autorize add-on
- Automated authorization enforcement detection
- HTTP traffic interception and replay with substituted credentials
- Multi-user support with per-user enforcement detectors
- Interception filters for request filtering
- Match/replace rules for request modification
- Color-coded results table with dynamic columns
- CSV and HTML export
- ZAP REST API for automation
